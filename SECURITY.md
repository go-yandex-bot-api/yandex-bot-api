# Security Policy

## Supported Versions

Currently, only the latest major version of `yandex-bot-api` is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this library seriously. 

If you discover a security vulnerability, please **DO NOT** open a public issue. Instead, please report it privately.

**How to report:**
1. Navigate to the [Security tab](https://github.com/go-yandex-bot-api/yandex-bot-api/security) in the repository.
2. Click on "Report a vulnerability" (Private vulnerability reporting must be enabled by the repo owner).
3. Provide a clear description of the vulnerability, including steps to reproduce.

Alternatively, you can contact the maintainers directly if an email is provided on their GitHub profiles.

We will try to review your report within 48 hours and release a patched version as soon as possible.
